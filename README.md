# Midas Core — JPMorgan Chase Virtual Internship

This repo contains my backend code for the *Midas Core* project, which I built as part of the *JPMorgan Chase Advanced Software Engineering Virtual Experience* on Forage.

### What this project does
Midas Core is a Spring Boot microservice that handles financial transactions in real-time. It processes payment events coming through a streaming pipeline, updates user balance records in a database, and communicates with external API services.

### What I worked on
* Set up the base Spring Boot application and configured dependencies using Maven.
* Configured Apache Kafka consumers to listen to incoming transaction topics in real-time.
* Integrated Spring Data JPA with an H2 database to track account balances and transaction history.
* Built REST integrations to connect Midas with external services for transaction validation and incentive handling.

### Built with
* *Java 17* & *Spring Boot*
* *Apache Kafka* (Event Streaming)
* *H2 Database & Spring Data JPA*
* *Maven* & *Git*
